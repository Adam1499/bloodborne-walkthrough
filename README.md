# Bloodborne – Lovecův deník

Interaktivní timeline bossů Bloodborne. Pořadí vychází z [boss orderu na Escapist Magazine](https://www.escapistmagazine.com/heres-the-best-bloodborne-boss-order-all-bosses-in-game/), mezi jednotlivé bosse jsou doplněné věci, které bys neměl minout (NPC questy, klíčové itemy, zbraně, runy a deadliny).

## Jak to otevřít

Stačí otevřít `index.html` v prohlížeči. Není potřeba nic instalovat ani spouštět build.

Na Windows:

```powershell
start index.html
```

## Co to umí

- 22 bossů včetně 5 bossů z DLC `The Old Hunters`.
- 81 „neminuout“ úkolů rozdělených mezi jednotlivé kroky.
- Odškrtávání bossů i jednotlivých úkolů.
- Progress bar a počty pro bosse a missables.
- Filtry `Vše` / `Bez DLC` / `Jen DLC` a přepínač `Skrýt splněné`.
- Ukládání postupu do `localStorage` prohlížeče (žádný server, žádný účet).
- Responzivní layout a tisková verze.

## Poznámky

- Chalice dungeon bossy v seznamu nejsou. Jsou volitelné a článek je vynechává; první `Pthumeru Chalice` dropne Blood-Starved Beast.
- U volitelných bossů a DLC je v kartě štítek, takže je poznáš na první pohled.
- U NPC questů jsou uvedené deadliny. Když je nestihneš, quest se často uzavře nebo NPC zmizí.
- Progress se ukládá pouze v tomto prohlížeči. Po smazání dat prohlížeče nebo po kliknutí na `Reset` se ztratí.
